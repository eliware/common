## Features

Eliware maintains this shared package for common Node.js APIs.
It re-exports filesystem, path, logger, error, signal, redaction, and Snowflake APIs.

## Requirements

Use Node.js 26 or later.

## Setup

Install the package.

```text
npm install @eliware/common
```
